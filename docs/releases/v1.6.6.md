码住 macOS 与 Windows 原生版。

### 下载

- **macOS**：`Mazhu-1.6.6-macOS-arm64.dmg`，适用于 Apple Silicon、macOS 26 或更高版本。打开 DMG，将“码住”拖到 Applications。
- **Windows**：`Mazhu-1.6.6-windows-x64.exe`，适用于 Windows 11 x64。运行安装程序后，从开始菜单打开“码住”；运行依赖已随包提供。

### 本版变化

- Windows 原生编辑界面、完整窗口操作和统一对齐的画布布局。
- 多图拖入、侧栏多选／框选／排序和右键移除。
- 固定窗口尺寸的笔刷、圈选提示、滚轮调节参数与画布平移。
- 修复图片 DPI 导致的马赛克错位，并优化持续涂抹和切图性能。
